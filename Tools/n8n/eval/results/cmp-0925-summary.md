## Что нужно для перехода (проверено запросами к API)

**Бот (AI Agent → OpenAI Chat Model v1.2 = Chat Completions): GPT-6 и GPT-5.6 не подключаются заменой имени.**

1. n8n шлёт `max_tokens`, а GPT-6 его отвергает (400 unsupported_parameter). В n8n (и в 2.36.7 — версии прода
   по README staging, — и в свежей 2.41.3) зашита библиотека `@langchain/openai 1.4.4`, которая не знает имена gpt-6. Поддержку добавили в LangChain
   только 2026-09-22 (#11625), n8n её ещё не подтянул.
2. «Размышление» у GPT-6 и GPT-5.6 по умолчанию `medium`. С ним поиск по прайсу и передача владельцу через Chat
   Completions запрещены (400 «Function tools with reasoning_effort are not supported… set reasoning_effort to 'none'»).
   Узел n8n умеет передать только low/medium/high, а `none` не умеет.
3. У GPT-6 Luna (и GPT-5.6 Luna) шаблонный `frequency_penalty` 0.2 вешает запрос на 61 с и даёт 500 (5 из 5).
4. API отвечает именем `gpt-6-luna` без даты версии — закрепить конкретный снимок пока нечем.

Встают без переделки только модели семейства gpt-5.4 (mini, полная, nano) — у них «размышление» по умолчанию `none`.

**Подсказки (HTTP Request с телом запроса в JSON, которое пишем сами) переводятся правкой тела:**
- `model`;
- `max_tokens` → `max_completion_tokens` (любая модель новее 4o отвергает `max_tokens`);
- `"reasoning_effort":"none"`.

`temperature 0.4` при `none` принимается.

## Выводы

1. **Подсказки → GPT-6 Luna.** 12 из 12, ≈0,14 ₸ за запрос (дешевле нынешних 0,21), та же скорость.
   Sol даёт то же качество в 20 раз дороже и вдвое медленнее. gpt-5.4-mini хуже Luna и в 8 раз дороже.
   Шаги: правка канонического Suggest Replies (три поля выше) → e2e-suggest на staging → деплой. Проверить,
   не рисует ли Luna таблицы в карточках, когда клиент просит «таблицей» (в наборе подсказок такого сценария нет).
2. **Автоответы — оставить gpt-5.4-mini.** Старшие модели (GPT-5.4, Sol) в продажных сценариях чаще переспрашивают
   и не передают готовый заказ владельцу. GPT-5.4 при этом примерно в 2,5 раза дороже при бюджете худшего случая
   ≈5–6 ₸ на диалог. Luna сильнее в нишевых уточнениях и казахском и в 7–10 раз дешевле, но требует переделки
   подключения в n8n и имеет свои дефекты (таблицы, повтор ответа). Вернуться к ней, когда n8n подтянет LangChain
   с поддержкой gpt-6 и `none`, — прогнать этот же набор.
3. **Дешёвый рычаг для текущей модели — промпт.** Устойчивый провал «цена запчасти до вопроса о машине» (5 из 5)
   правится правилом ниши с прогоном «до/после» на этом наборе.
4. **Харнесс.**
   - `no_discount` сделать нечувствительным к отказам и пересказу просьбы;
   - добавить проверку повтора ответа — сейчас его не ловит ни одна проверка.
