# Сценарий демо-видео для ревью (~90 секунд)

Цель: показать ревьюеру ВЕСЬ путь, который он не может пройти сам (нужен живой
WhatsApp). Снимать экран устройства (iOS-запись экрана), без монтажа, тёмная тема.
Понадобятся: телефон с приложением, второй телефон с WhatsApp «клиента», номер
с уже установленным WhatsApp для авторизации.

Подготовка до записи: свежая установка (или «Удалить все данные»), второй телефон
под рукой, в настройках бота заранее ничего нет.

**PII-гигиена (аудит 2026-08-30 — видео уходит Apple и Google, это внешний
материал):**
- Авторизовать ТОЛЬКО выделенный тестовый номер WhatsApp с НУЛЁМ существующих
  чатов (свежая SIM/eSIM). Подключение сразу синхронизирует весь список чатов —
  живой номер владельца выложит реальные имена, номера и превью переписки
  клиентов прямо в материалы ревью.
- «Клиент» — второй тестовый телефон с вымышленным именем контакта; его номер
  виден как заголовок чата в шагах 4–5.
- В кадре не показывать никакие серверные дашборды/консоли — только приложение
  и (шаг 2а) экран WhatsApp.
- Перед заливкой пересмотреть финальный ролик покадрово на предмет реальных
  номеров/имён.

| # | Время | Действие на экране | Что это доказывает ревьюеру |
|---|-------|--------------------|------------------------------|
| 1 | 0:00–0:10 | Запуск, онбординг, экран «Боты» пустой | приложение стартует, RU-интерфейс |
| 2 | 0:10–0:30 | «+ бот» → имя → канал WhatsApp → **QR/код на экране** → сканируем вторым способом (код) с ТЕСТОВОГО телефона → статус «Подключено» | авторизация СОБСТВЕННОГО аккаунта, как WhatsApp Web |
| 2а | +5 сек | В WhatsApp тестового телефона открыть **Настройки → Связанные устройства** — в списке видно подключение | визуальное доказательство тезиса «exactly like WhatsApp Web» из review notes |
| 3 | 0:30–0:40 | Заполняем «Бизнес»: описание пару строк, 1 товар с ценой | откуда ИИ берёт знания |
| 4 | 0:40–0:55 | Со второго телефона «клиент» пишет вопрос о цене → в приложении виден входящий → **бот отвечает сам** (режим «Авто») | ядро продукта: автоответ ИИ |
| 5 | 0:55–1:10 | Переключаем чат в «Вместе» → клиент пишет ещё → появляются **карточки-подсказки** → тапаем одну → ответ ушёл | полуавтоматический режим |
| 6 | 1:10–1:20 | Вкладка «Сводка»: итоги диалога, статус | аналитика |
| 7 | 1:20–1:30 | Пилюля «Пробный · N дн.» → **пейволл**: тумблер Месяц/Год, 3 тарифа, чеклист, ссылки «Условия использования · Политика конфиденциальности» (тапнуть одну — открылась), «Восстановить покупки» | покупочная поверхность и юр-ссылки на месте |

Финал: стоп записи. Залить непубличной ссылкой (YouTube unlisted / Google Drive
по ссылке), вставить URL в review notes. Проверить, что видео открывается
в инкогнито-окне без логина.

## Режим A — съёмка в iOS Simulator (решение 2026-09-03)

Тестового номера у владельца пока нет, поэтому видео снимает Claude в симуляторе
(продолжение — в отдельной сессии; полный план и ловушки — в памяти проекта
`project_demo_video_mode_a`). Кратко:

- Сборка: Player Settings → iOS → **Target SDK = Simulator**, RELEASE (без Development
  Build — водяной знак попадёт в кадр). После съёмки **вернуть Device SDK** — иначе
  следующий архив для ASC не соберётся. Интел-мак + Xcode 26: ~час, редактор занят.
- Запись: `xcrun simctl io booted recordVideo demo.mp4`; статус-бар замаскировать
  `xcrun simctl status_bar booted override --time 9:41 --batteryLevel 100 --cellularBars 4 --wifiBars 3`.
- Монтаж: ffmpeg — паузы, ускорение ожиданий, подписи к шагам, размытие цифр; итог ~90 с MP4.
- **Номер всё равно нужен**: на шаге подключения QR/код должен отсканировать чей-то WhatsApp.
  Личный WhatsApp владельца — НЕЛЬЗЯ (реальные чаты в кадре). Варианты без eSIM:
  неиспользуемый номер семьи/компании + WhatsApp Business на iPhone; офисный городской
  номер (подтверждение звонком); телефон друга с пустым WhatsApp. Арендные номера — нет.
- Пока номера нет, снимается всё до авторизации и не требующее чатов (онбординг, визард,
  пейволл); живая часть («Авто», «Вместе», Сводка с данными) дописывается позже.
- Участие владельца: ~30 с на скан/код + 2–3 сообщения «клиента» с личного телефона.
