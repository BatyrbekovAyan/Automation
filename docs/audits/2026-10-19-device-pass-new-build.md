# Device pass новой сборки (клиент A1/F2 + learning A/B + части A и B) — сценарий для владельца

Одна страница, по которой проходится первая сборка с `main` после 2026-10-14. Подробные сценарии частей A («защита платящих») и
B («расписание бота») уже написаны — `docs/audits/2026-10-17-bot-schedule/device-pass.md` (§A, §B, §C, вопросы D); здесь они
только названы, не повторены. Источники остальных пунктов: `docs/audits/2026-10-09-followups/F1F2-plan.md` §5.4, пакет
`docs/audits/release-package.md` §8 (canary), learning A/B (`docs/superpowers/specs/2026-09-25-…`, `…/2026-10-14-…`),
`docs/store/play-console.md` §6 (Android).

## 0. Перед началом

- **Сборка** — iOS (TestFlight) и Android (Internal testing) с `main`; номер коммита назовёт контроллер. До установки:
  `Tools/store/inspect-artifact.sh <aab|ipa>` — в артефакте нет `wappiAuthToken` и `n8nAPIKey` (A1).
- **Что на проде, а что нет.** Сервер A1/F1/F2/M4/Q1, learning A и B, часть A — выложены. **Пакет B («расписание», `crSetSchedule001`)
  НЕ выложен:** до него секция «Расписание работы» в приложении будет показывать «Расписание ещё не дошло до сервера» → «Не удалось
  сохранить…», а бот — отвечать в любое время. Это не дефект сборки. Пункты §6 ниже — только после выкладки пакета B (отдельное «да»).
- **Устройства:** iPhone + Android 10+ (тёмная тема по умолчанию; Android дополнительно на ширине 720 — старый Galaxy). Второй
  телефон/номер — писать боту с него. Боты живые: клиентам не писать, после прохода вернуть режимы.
- **Аккаунты:** тестовая подписка (sandbox / License testing) и триальный аккаунт (свежая установка).
- Скриншоты — в чат с номером пункта. Строки «Исполнитель:» — проверки на сервере (только чтение), от вас ничего не нужно.

## 1. Свежая установка и первый живой бот (canary — на проде ещё не было живого бота после сентябрьских деплоев)

1. Установить, пройти онбординг, создать бота через мастер (WhatsApp, QR или код; при коде — «Получить код ещё раз» один раз).
   - Ожидание: пара проходит, карточка бота: подстрока «Подключение…» → тип бизнеса + иконка WA; в шапке «Пробный · 5 дн.»
     появился ПОСЛЕ привязки канала (триал стартует с канала, не с установки).
   - Исполнитель: `bot_profiles` — одна живая строка с `bot_key`, `owner_id` = установка; один клон, активен.
2. Настройки → заполнить описание, контакты, 2–3 товара, загрузить прайс (PDF/xlsx) → «Сохранить».
3. «Проверить бота» (лист Test Dialog): ответ приходит, источники названы, `sent:false` (клиенту ничего не ушло).
4. Со второго номера одно сообщение → один ответ бота (не два); фото без текста → ответ по-русски «Напишите, пожалуйста, текстом…».
   - Исполнитель: `reply_events` одна строка `sent` с `transport_message_id`; память — одна ai-строка с `delivery='sent'`.
5. Переключить чат в «Вместе» во время генерации (написать и сразу переключить) → ответ не уходит.
   - Исполнитель: строка `cancelled_mode`.
6. Ответить клиенту С ТЕЛЕФОНА (из самого WhatsApp) → в «Сводке» через минуту строка с исходом; бот в «Авто» на следующий вопрос
   клиента о договорённости повторяет её (Q1: «Владелец: …» в памяти).
   - Исполнитель: `chat_history_events` строка `owner_phone`; `Outcome` без `other:*`.
7. Заявка: клиент просит менеджера → бот говорит, что передал; в «Избранном» аккаунта бота — уведомление без текста клиента; в
   «Сводке» — «Заявка · …»; чат на паузе до вашего «Авто» (п. 4.5 ниже).
8. Казахский вопрос → ответ по-казахски (допускается 1 из 7 по-русски — модель).

## 2. F1/F2 — линия бота и переподключение (`F1F2-plan.md` §5.4)

1. «Сменить номер» → привязать снова → бот отвечает, прайсы и память на месте. Исполнитель: клон тот же, нового не появилось.
2. «Получить код ещё раз» (WA) → новый профиль → отвечает. Исполнитель: заменённый клон удалён (ветка A свипа), прайсы на новом.
   Известный остаток (CLAUDE.md, ChannelHealth): если код запрошен ровно в момент, когда предыдущий профиль только что спарился, —
   проверить, что бот всё равно отвечает одним клоном.
3. Выключить сеть во время Create (сразу после пары) → «Не удалось сохранить» → открыть настройки снова при сети → Create повторяется
   и проходит (`CreatePending`).
4. Бот с истёкшим триалом (триальный аккаунт через 4 д 17 ч, или контроллер ретирует строку на стенде): запуск → подстрока
   «Отключён · пробный период закончился», чаты — пустое состояние «Бот отключён», капсула «Подключить»; лог без повторяющихся 403.
5. До оплаты: баннер «Бот отключён» в настройках, «Выбрать тариф» открывает пейволл.
6. Покупка (StoreKit 1 на iOS — лист появляется за секунду; Android — лицензионный тестер) → «Подтверждаем оплату…» → лист
   «Подключите ботов снова» → «Подключить» → QR/код → пара → бот отвечает ценой из прайса, помнит прежний диалог, «Сводка» показывает
   прежние исходы. «Позже» = Назад.
7. Двухканальный бот на «Старте»: подключён WA → «Подключить» у TG открывает лист лимита канала.
8. Удаление переподключённого бота → «Удалить бота» проходит с первого раза. Бот только с удалённым каналом (`app_delete`) →
   «Удаление не завершено · удалите ещё раз» → удаляется. Исполнитель: линия стёрта (профили, память, наборы, расписание).
9. Telegram: канал выключен → сессия Telegram слетела → включение → переиспользование клона (без второго).

## 3. Learning A — «показано → отправлено»

1. В чате с панелью «Вместе»: отправить карточку как есть, отправить правленую, набрать своё, отправить без панели.
   - Исполнитель: четыре строки `owner_app` с `origin_kind` card / edited / typed / none; у card `origin_top1` 1 или 0, `origin_set` = число
     карточек; `suggestion_sets` — по строке на показанный набор.
2. Telegram: ответить клиенту ЦИТАТОЙ (reply) из приложения. Исполнитель: строка истории с непустым `chat_id`, память `pid:chat`.
3. Десять отправок карточек подряд (можно в одном чате) → панель переходит из холодного старта (≥ 3 разных хода) к ПРЕДПОЧТЕНИЯМ.
   Исполнитель: в выполнении Suggest Replies `stage = trained` (счётчик пишется при отправке, не при тапе).
4. «Вы бот?» → честный «ассистент {название бизнеса}» (имя — после первого сохранения настроек). Посторонний вопрос → одна карточка
   «Отказ» в панели, в «Авто» — фраза про вопросы бизнеса; спам → одно слово, не пустота.

## 4. Learning B — замок «Авто»

1. Новый бот в «Вместе»: капсула на карточке — «Учится · 0/20» (после ответа Get Usage; переоткрыть вкладку «Боты»). Ширина растёт,
   название бота не наезжает; лампы-точки нет. Светлая и тёмная тема.
2. Тап по капсуле → лист «Бот ещё учится» («Авто откроется, когда панель угадает ваш ответ 10 раз из последних 20 — сейчас 0 из 20…»).
   «Понятно» — закрывает, ничего не включает. Android «Назад» = «Понятно». Тап по подложке = «Понятно».
3. Тап → «Включить всё равно» → прежний вопрос «Включить авто-режим?» → «Включить» → капсула «Авто» горит. Выключить тапом — мгновенно,
   без листа. Включить снова → лист снова (так задумано).
4. Шапка чатов «Авто» и строка переключателя ботов у запертого бота — тот же лист; у готового/старого бота — сразу прежний вопрос.
5. Чат бота, стоящего в «Авто», на паузе (после заявки из п. 1.7 или вручную «Вместе» в чате) → кнопка «Авто» в чате → БЕЗ листа
   «Бот ещё учится», сразу прежний вопрос «в этом чате». Тот же чат у бота в «Вместе» → лист с текстом «…в этом чате можно и сейчас».
6. После п. 3.1 (одна отправка карточки с совпадением) переоткрыть «Боты» → «Учится · 1/20» (считается только с показанным набором,
   группы не считаются).
   - Исполнитель: Get Usage этой установки — `readiness[{botKey, matches, total, chats, days, ready}]`; `report-learning.py --prod`.

## 7. Android (play-console §6) и iOS — общее

- Android «Назад» на каждом экране: чат, настройки, пейволл, любой попап/лист (в т. ч. «Бот ещё учится», «Подключите ботов снова»),
  страницы профиля, дриллдаун «Сводки»; в корне — сворачивание; во время slide-in чата и под LoadingPanel — проглатывается.
- Клавиатура Android (gesture-nav И 3-кнопочная): композер и листы ровно на высоту IME — без полосы 92u и без подъёма на весь экран;
  лист товара и вкладка «Бизнес» поднимаются. Иконка под круглой/squircle масками. Пикер без запроса разрешений на Android 13+,
  .docx выбирается. Пейволл: цены в формате Play («9 990,00 ₸»), отмена покупки без красного уведомления, смена тарифа — одна подписка.
- Слой выделения текста (долгое нажатие, пины, меню) на Android — впервые.
- iOS: свайп-назад из чата начинается от самого края (над композером и над панелью подсказок); пейволл StoreKit 1 показывает лист
  за секунду; на iPad в режиме совместимости (если есть) — покупка тоже.
- Экран «Подписка» и пейволл: ссылки «Условия» / «Конфиденциальность» открываются (privacy §3 про метки учёбы — на сайте).
