# Монетизация: тарифы, триал, биллинг — дизайн

**Дата:** 2026-08-21 · **Статус:** утверждено владельцем (раунды 1–3 обсуждения), готово к планированию
**Исследование:** workflow-ресёрч 2026-07-26 (10 агентов): Wappi/конкуренты/правила сторов/LLM-цены/курсы НБК — все ключевые числа verified на первоисточниках.

## 1. Модель

Подписка через store IAP (RevenueCat), **без freemium**, триал 5 дней без карты. Тарифы отличаются ТОЛЬКО масштабом (боты · каналы · диалоги + кросс-Сводка); все функции — во всех тарифах по максимуму. Питч пейволла: «Все возможности — в каждом тарифе. Платите только за масштаб».

## 2. Тарифная матрица (утверждена)

| | Старт | Бизнес ★Популярный | Сеть |
|---|---|---|---|
| Цена/мес | 9 990 ₸ | 19 990 ₸ | 39 900 ₸ |
| Цена/год («до −17%») | 99 000 ₸ | 198 990 ₸ | 399 990 ₸ |
| Боты | 1 | 3 | 5 |
| Каналы (слоты подключённых профилей) | 1 | 3 | 5 |
| Диалоги ИИ/мес | 300 | 1 000 | 3 000 |
| Сводка по всем ботам (кросс-бот) | — | ✓ | ✓ |

**Определение «диалог ИИ» (утверждено):** один клиент + календарные сутки = 1 диалог, сколько бы ответов бот ни дал этому клиенту за сутки. Считается на аккаунт (пул по всем ботам/каналам).

**Слот канала** = авторизованный Wappi-профиль. Отключение канала (logout/удаление профиля) освобождает слот.

**«Во всех тарифах» (блок на пейволле, обязан соответствовать продукту на момент запуска):**
умный ИИ последнего поколения · понимает голосовые (уже в Авто-пути ботов) · прайс-листы без лимита, файлы и фото · режимы «Авто» и «Вместе» · Сводка за всё время + экспорт · алерты «клиент готов купить» / «канал отключился» · недельный отчёт в Telegram · расписание работы бота · докупка диалогов.

**Add-on:** топ-ап 500 диалогов — 3 900 ₸ (consumable, не продлевается). Семантика (решение владельца 2026-08-26): резерв — списывается по одному диалогу ТОЛЬКО сверх исчерпанной месячной квоты, со временем не сгорает.

**Промо запуска:** founding −30% первым 100 подписчикам (лок на 12 мес, бейдж «Основатель»); рефералка через store offer codes — месяц в подарок обеим сторонам.

## 3. Триал (утверждено: 5 дней)

- 5 дней, **без карты и без регистрации**, уровень «Бизнес» (до 3 ботов / 3 каналов), кап 150 диалогов.
- Enforcement: device-keyed v1 (реализация: PlayerPrefs — НЕ Keychain; дыра через reinstall принята осознанно — до появления бэкенд-аккаунтов).
- День 5 — «чек ценности»: экран со статистикой ЕГО бота (диалоги, заказы из Сводки, ночные ответы) над кнопкой подписки.
- **Экономика триала = ~0 ₸ Wappi** благодаря партнёрским условиям владельца: каждый новый профиль имеет 5 бесплатных дней; **на 6-й день Wappi списывает ретроактивно за все 6 дней** (23₽ × 6 = 138₽ ≈ 840 ₸). Отсюда жёсткое правило §5 (свип).

## 4. Юнит-экономика (основания цен)

- **Wappi (партнёрка владельца, уже действует): 23₽/день/профиль**, посуточно, постоплата. Устоявшийся месяц ≈ 700₽ ≈ 4 256 ₸/канал (курс 6.08 ₸/₽, НБК 26.07.2026). ⚠️ Допущение: ставка действует и на tapi (Telegram) — владелец подтверждает у Wappi.
- **LLM:** рабочая модель класса gpt-5.4-mini + обязательный prompt caching → ~4 ₸/диалог (6 ответов × ~2 500 in / 150 out токенов). Без кэширования ~7.3 ₸ — худший случай «Сети» уходит в −9 900 ₸, поэтому кэширование — часть Блока 1, не оптимизация «потом».
  - ⚠️ Floor выведен эмпирически (Task 13, 2026-08-21) на живом снапшоте `gpt-5.4-mini-2026-03-17` за алиасом `gpt-5.4-mini`; алиас может уехать на новый снапшот без предупреждения — пересчитать floor при следующей проверке модели.
- **Стор:** 15% (Apple Small Business Program — записаться; Google 15% на подписки). KZ-сторфронты: внешние ссылки/steering запрещены — не пытаться.
- Маржа (net = цена − 15%): Старт worst +32% / typical ~40%; Бизнес worst −1.5% / typical ~31%; Сеть worst ~0% / typical ~37%. Худший случай = все слоты весь месяц + вся квота; принят осознанно: посуточность Wappi поднимает средний кейс, топ-апы (~69% маржи) страхуют сверху.
- **Триггер пересмотра:** если доля полностью загруженных аккаунтов «Бизнес» (3/3 + квота) в когорте станет заметной — третий канал переводится в add-on (+6 900 ₸) для новых подписок. Метрику считать из серверной таблицы профилей+счётчика.

## 5. Серверная часть (n8n + Supabase)

1. **Зеркало подписок:** RevenueCat webhooks → n8n → Supabase `subscribers` (appUserID, тариф, статус, период). Источник истины для серверных enforcement'ов.
2. **Счётчик диалогов:** в обоих бот-workflow — upsert `dialog_counts` (appUserID, chatId, date) при первом ответе клиенту за сутки; агрегат за месяц читается приложением (виджет «214 из 300») и enforcement'ом.
3. **Enforcement квоты:** превышение месячного лимита (и пустого резерва) → бот аккаунта переводится в «Вместе»-поведение (подсказки без автоответа), НЕ молчание; реализация: сервер глушит автоответ (гейт квоты), клиент включает effective-semi (панель подсказок доступна). Подсказки «Вместе» БЕСПЛАТНЫ (не списывают диалоги; решение владельца 2026-08-26), но гейтуются подпиской: истёкший/неизвестный аккаунт — отказ, over-quota — разрешён (это и есть фолбэк) + дневной анти-абьюз потолок на аккаунт. 80% — уведомление (v1: индикатор в приложении).
4. **Свип жизненного цикла профилей (критично из-за ретро-списания 6-го дня):**
   - при создании профиля Create*Workflow регистрирует `{profileId, appUserID, channel, createdAt}` в Supabase;
   - ежедневный n8n-свип: профиль старше ~4.7 дня И у владельца нет активной подписки → `profile/delete` (запас до суточной границы дня 6);
   - отвал платника: подписка неактивна → grace 3 дня (уведомление «оплатите — бот продолжит») → удаление профилей. Каждый день зомби-профиля стоит ~140 ₸.
   - Существующий hourly orphan-sweep НЕ покрывает этот случай (он чистит только неавторизованные профили) — это отдельный механизм рядом.
   - UX-следствие: удаление профиля = разлогин WhatsApp; повторная подписка = повторная авторизация (QR/код). Принято.
5. **Гейты ботов/каналов:** первично в клиенте (блокировка создания сверх лимита); сервер сверяет число зарегистрированных профилей appUserID с тарифом при создании профиля (отказ создающего вебхука при превышении).

## 6. Клиентская часть (Unity)

- **RevenueCat purchases-unity** (9.5.x), анонимные appUserID, restore по store-аккаунту. SKU: 3 тарифа × (месяц, год) + consumable топ-ап = 7 продуктов.
- **Пейволл** — полноэкранный slide-in overlay (паттерн AddBotPanel, свой builder): заголовок «Все возможности — в каждом тарифе», тумблер Месяц/Год («до −17%»), 3 компактные карточки (только числа; Бизнес выделен рамкой accentFill + бейдж «Популярный»), общий чеклист «Во всех тарифах», CTA «Попробовать 5 дней бесплатно» в thumb-zone, «Восстановить покупки». Тёмная/светлая — через Theme-токены.
- **Боты:** пилюля триала в шапке («Пробный · N дн.» → пейволл); строка-счётчик аккаунта «Диалоги ИИ · 214 из 300» с прогрессом (accent → warning 80% → danger 100%) над списком карточек; dashed-карточка «+ бот» показывает остаток лимита.
- **Профиль → «Подписка»** — новая под-страница в существующем ProfileSubPages-паттерне: карточка тарифа + статус + следующее списание, счётчики, «Изменить тариф» / «Купить 500 диалогов» / «Восстановить покупки» / «Отменить».
- **Чек ценности (день 5):** экран из данных DashboardMetrics поверх пейволла.
- **Гейты в местах действия** (bottom-sheet, паттерн ItemEditSheet): создание бота сверх лимита, подключение канала сверх лимита.
- Утверждённые мокапы — в переписке (тёмная тема, палитра Theme_Dark: #171C24 / #3E61C6 / #ECF0F6).

## 7. Блоки работ

**Блок 1 — ядро монетизации (~2.5–3 нед):** RevenueCat + SKU в консолях сторов; пейволл + Подписка + триал + гейты; счётчик диалогов + enforcement; свип профилей (§5.4); топ-ап; prompt caching + единая модель в бот-workflow.
Store-статус: аккаунты есть, приложение не опубликовано; Apple Developer оплачивается 2026-08-22 (App Store Connect станет доступен после активации, обычно ≤48ч).

**Блок 2 — обещания витрины (~1.5–2 нед, параллельно; ДО включения пейволла):** алерты «клиент готов купить»/«нужен владелец» (v1 — в Telegram владельцу, паттерн SendToTelegram; пуш-инфры в приложении нет); алерт «канал отключился»; недельный отчёт в Telegram; экспорт Сводки; период «Всё время» в Сводке (DashboardMetrics/DashboardPage — обещан на пейволле строкой «Сводка за всё время»); расписание работы бота (UI + время-гейт поверх Suppressed?); транскрипт голосовых в панель «Вместе» (в Авто уже есть: Download Audio → Transcribe Audio → AI Agent в обоих шаблонах; старые клоны ботов обновляются пересозданием/редактированием); клиентская сверка профилей при запуске (Wappi 404/unauthorized по сохранённому profile_id → бот помечается «не подключён» — закрывает принятое в v1 враньё списка ботов после переноса подписки, см. §8); identity-push при запуске (в проде зеркало после переустановки лечится только со следующим RC-событием — до месяца, а свип может успеть удалить профили платящего; alias-вход на сервер ТОЛЬКО через аутентифицированный RC-вебхук, НИКОГДА через неаутентифицированный GetUsage) + журнал идемпотентности по RC event.id.

**Правило запуска:** пейволл не публикуется, пока каждая строка «Во всех тарифах» не работает. Плашек «скоро» нет.

## 8. Зафиксированные решения владельца

- Триал 5 дней (не 7) — под бесплатное окно Wappi. ✓
- Пользователей кроме владельца нет → без переходных правил/grandfather. ✓
- Диалог = клиент + календарные сутки. ✓
- Годовая = «12 за 10» (−16.7%), не −20%. ✓ → изменено 2026-08-25: сетка Apple не дала 399 000 для Сети (год) — бейдж заменён на честный «до −17%».
- Матрица 1/3/5 ботов · 1/3/5 каналов · 300/1000/3000 диалогов; «всё по максимуму везде». ✓
- Экономика: вариант C (принять матрицу при партнёрских условиях Wappi + свип + мониторинг full-util-доли). ✓
- Перенос подписки между устройствами/переустановка (2026-08-26): сервер гасит старую личность (боты старого устройства перестают отвечать, профили удаляются после grace), при этом список ботов на старом устройстве продолжает их ПОКАЗЫВАТЬ (PlayerPrefs) — принято для v1 осознанно; клиентская сверка профилей — в Блок 2. ✓
