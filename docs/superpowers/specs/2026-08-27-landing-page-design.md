# Лендинг choosereply.com + приём заявок — дизайн-спека

Дата: 2026-08-27. Статус: одобрено владельцем (чат, «ok»). Предшественник: заглушка
«Скоро запуск», задеплоенная при миграции n8n на VPS (см. Tools/n8n/README.md, секция Prod).

## Цель

1. Продающий одностраничник на `https://choosereply.com` для малого бизнеса КЗ/СНГ —
   собирает заявки на ранний доступ до релиза в сторах.
2. Юридические страницы на вшитых в приложение путях `/privacy.html` и `/terms.html`
   (`LegalLinks.cs`) — снимает блокер стор-подачи.
3. Копилка заявок: таблица `landing_leads` в том же Supabase Postgres, приём через n8n.

## Решения (одобрены)

- **CTA до релиза**: форма «оставить заявку» (имя + телефон/WhatsApp), НЕ WhatsApp-кнопка.
- **Тарифы**: показываем с ценами из `PlanCatalog.cs` — Триал 5 дней/150 диалогов;
  Старт 1 бот/1 канал/300 диалогов — 9 990 ₸/мес (год 99 000 ₸); Бизнес 3/3/1000 —
  19 990 ₸/мес (год 198 990 ₸, помечен «популярный»); Сеть 5/5/3000 — 39 900 ₸/мес
  (год 399 990 ₸). Цены на странице — literals; при смене тарифов править руками.
- **Технология**: чистый HTML/CSS + минимальный JS для формы (fetch). Без фреймворков,
  без сборки. Шрифт Manrope (Google Fonts, кириллица) с системным fallback.
- **Направление**: тёмный «чернильный» фон (как дефолт-тема приложения), циановый акцент
  (#22D3EE — палитра робота), робот `Tools/hero_robot.svg` инлайном в hero. Mobile-first.
  Вся страница по-русски (RU-only, как приложение).

## Структура страницы (index.html, одна страница)

1. Шапка: «Choose Reply» + якоря (Возможности, Тарифы) + кнопка «Оставить заявку» (#lead).
2. Hero: робот; H1 «ИИ-продавец в вашем WhatsApp»; подзаголовок про 24/7 с номера владельца
   и контроль каждого ответа; плашки «Скоро в App Store / Google Play» (без ссылок); CTA #lead.
3. «Как это работает»: 3 шага (подключить номер → загрузить прайс → бот отвечает сам
   или предлагает варианты на выбор).
4. Возможности, 6 карточек: Авто/Вместе; знание прайс-листов; WhatsApp + Telegram;
   сводка итогов диалогов; работа с номера владельца; русский язык. Ниже лента 6 ниш
   (автозапчасти, опт, цветы, Kaspi-продавцы, обучение, ремонт телефонов).
5. Тарифы: плашка триала + 3 карточки (см. цены выше) + строка про докупку диалогов
   (500 за 3 900 ₸) и оплату через подписку в приложении.
6. Форма #lead: поля Имя (опционально), Телефон (required); honeypot-поле `website`
   (скрыто, должно остаться пустым); submit через fetch **form-encoded** (без CORS-preflight)
   на `https://n8n.choosereply.com/webhook/LandingLead`; успех — inline «Спасибо! Напишем
   вам в WhatsApp»; ошибка — «Не получилось, напишите нам: …» + повтор.
7. Футер: © Choose Reply, ссылки «Политика конфиденциальности» → /privacy.html,
   «Условия использования» → /terms.html.

Мета: title/description; OG title+description (+og:image, если удастся отрендерить PNG
локально штатными средствами macOS; иначе без картинки); favicon (SVG; PNG — если удастся).

## Приём заявок (n8n `LandingLead`)

- Новый воркфлоу на проде n8n.choosereply.com, по образцу Set Reply Mode
  (`SCLcpn6DMDG3Z4VN`): Webhook POST `LandingLead` → Code-валидация → Postgres INSERT
  (credential `vvRrFiEXzLVqKjOx`) → Respond.
- Валидация: honeypot `website` непустой → тихий `{success:true}` (боту не сообщаем);
  phone: обязателен, 6..32 символов из `[0-9+()\-\s]`; name ≤ 80; всё обрезается.
  Невалидно → `{success:false, error:"bad_request"}` (стиль Set Reply Mode).
- INSERT в `landing_leads`; ошибка БД → `{success:false, error:"db"}` (HTTP 500 не
  обязателен — форма показывает fallback-контакт при любом `success:false`).
- Таблица (миграция `Tools/n8n/sql/2026-08-27-landing-leads.sql`):
  `id identity PK, name text, phone text not null, source text, user_agent text,
  created_at timestamptz default now()`; RLS enable + revoke anon/authenticated
  (по образцу hardening-миграций документов). Применение — через одноразовый
  harness на проде; если классификатор заблокирует DDL — готовый скрипт владельцу
  (паттерн fix-subscriber.py).
- Канонический JSON после деплоя экспортируется в `Tools/n8n/workflows/<id>-Landing_Lead.json`
  (id с прода), README-таблица и счётчик «16 canonical» обновляются на 17;
  проверить, что parity-гейты не пиняют число 16.
- Уведомления о заявках: v1 — нет (только таблица). Fast-follow (вне спеки):
  Telegram-уведомление владельцу; потребует токен бота credential'ом в n8n.

## Юридические страницы

`docs/legal/privacy.html` и `terms.html` выкладываются НА вшитые пути как есть; тексты
не редактируются. Жёлтые поля «[Заполнить…]» (реквизиты ИП/ТОО) остаются до заполнения
владельцем — блокер стор-подачи, не лендинга.

## Деплой и проверка

- Файлы → VPS `~/choosereply/site/` (scp, ssh-алиас `choosereply`); Caddy уже отдаёт сайт.
- Проверки: `curl` 200 на `/`, `/privacy.html`, `/terms.html`; тестовый POST формы
  (телефон-заглушка, пометить именем `test`) → строка в `landing_leads`; мобильная
  ширина 375px и десктоп визуально (скриншот через браузер-панель).
- Просмотр заявок владельцем: v1 — по запросу через Claude/n8n executions; нормальный
  канал (Telegram) — fast-follow.

honeypot, длины; пересмотреть при реальном спаме).
