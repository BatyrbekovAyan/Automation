Финалисты · Three styles · Nine palettes · 2026

Three finalists, nine ways to color them.

Spatial Depth, Liquid Glass and Refined Modern — each in three palettes, each palette shown across three real screens: «Сводка» (dashboard), «Боты» (bot list with activation switches) and настройки бота (the 5-tab form). Within a style the material recipe is frozen; only the color tokens change — which is exactly how the Unity theme system will work. Status colors, the activation-switch green and channel dots are held constant everywhere: semantics never follow fashion.

01 — направление

Spatial Depth

Palette changes the light, not the material. All three variants share the identical recipe — 6% white panes, 22 px backdrop blur, the same shadow stack — only the substrate and the key light move. Note how the glass hero pane automatically takes on each variant's glow through the blur.

02 — направление

Liquid Glass

The glass itself is colorless; the world behind it is not. The white-glass recipe — specular top edge, darker inner bottom edge, 24 px blur at ×1.9 saturation — never changes. Each palette repaints the backdrop the glass refracts, and the ink family shifts with it.

03 — направление

Refined Modern

Pure tokens. Same hairline logic, same three-layer elevation, same radius math — each palette is one token-file swap, including the dark theme, which costs nothing extra once tokens exist. This is the architecture the Unity restyle needs regardless of which style wins.

How to read this page

Compare vertically, not horizontally: pick the screen you care about most (the Settings form is where the styles differ hardest) and scan it down through all nine variants. A palette that wins on the dashboard but fails on the form is not a winner.

What is deliberately constant everywhere: the five outcome-status colors, the green activation switch, WhatsApp/Telegram channel dots, type sizes, spacing, and touch-target geometry. If a variant looks different in those, that would be a bug — meaning is never allowed to change with the skin.

The build prompts behind each style live in docs/design/ui-restyle/MASTER-PROMPT.md; every palette above corresponds to one token block that drops into its style's module.
