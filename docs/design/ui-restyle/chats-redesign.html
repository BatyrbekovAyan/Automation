Same bones, fixed hierarchy.

Left is the app today, drawn from the measured prefab — row 200u, avatar 140u, name 44u, preview 38u, timestamp 38u bold, badge 48u. Right is the proposal. Colours are unchanged — this is layout and type only; the palette flip to «Чернильный» is the next phase.

Nothing moves that does not need to: the row height, the avatar size and the overall structure are kept, so the screen stays familiar to someone who uses it every day.

Every change, and why

ElementNowProposedReason
Timestamp38u, bold, #66666630u, medium, #666666 (unchanged ink) Today it is the same size as the message preview and bolder than the contact name — the least important text on the row is drawn the loudest. Size and weight alone fix the hierarchy; the ink stays #666666 because lightening it to #8E8E93 would drop it to 3.26:1 and fail the text floor.
Contact name44u, regular46u, semibold Name-to-preview ratio is 1.16× today, which is not enough to read as hierarchy. Weight does the work rather than size, so the row height is unaffected.
Preview38u36u Widens the gap to the name to 1.28× without shrinking legibility below the 12sp floor.
Dividerfull-bleed, #CCCCCCinset to the text column, #E4E6EB Inset dividers let the avatar column read as one continuous rail — the standard iOS/WhatsApp treatment. The lighter value stops the separator competing with content.
Unread badge48u, #26B25A, white text 2.76:152u, #17803F, white text 5.00:1 Fixes a real accessibility failure carried over from today. Same green family, darkened until white text clears 4.5:1. (#1F8F4A was tried first and measured 4.13:1 — still failing.)

What this is not. No colour flip, no new components, no structural rework — the wirer bindings from phase 2 all still apply. The only new token needed is a darker unread green; everything else is a size, weight or inset change on objects that already exist.

The one thing that needs your eye: the unread green moves from #26B25A to #17803F to fix the contrast failure. It is a visibly deeper green. If you would rather keep the exact WhatsApp-ish green and accept 2.76:1, say so — the alternative is darkening the badge text instead of the fill, which reads less like WhatsApp but keeps the brighter green.
