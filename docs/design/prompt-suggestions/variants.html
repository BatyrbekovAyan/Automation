«Промпт» → подсказки под полем

Шесть направлений для тапабельных мини-промптов под основным полем «Промпт» в настройках бота. Всё нарисовано в текущей тёмной теме приложения (Theme_Dark), в реальных пропорциях экрана и с реальными русскими строками.

Свободного места под полем сегодня ≈ 334 dp (≈ 925 ref units) — хватает на 3 ряда чипов или список из 5–6 строк без сжатия поля «Промпт».

V1 Облако чипов

Пилюли переносятся по строкам прямо под полем. Тап = строка добавляется в конец промпта, чип помечается галочкой. «Ещё 26» открывает полный список.

Что рекомендую

V1 + V4: облако чипов под полем показывает 8–10 самых полезных подсказок (их видно сразу — фича себя продаёт), а «Ещё 26 ›» открывает шторку из V4 с поиском, категориями и мультивыбором. Обе части живут на одной модели данных, шторку можно сделать вторым шагом.

Подсказки при этом стоит фильтровать по типу бизнеса бота — у автозапчастей и у цветов разные полезные строки, а вертикали в проекте уже есть.

Отдельно решим: тап дописывает строку в конец промпта с новой строки; уже добавленная строка помечается галочкой; повторный тап — убирает её обратно.
