# Sketch 006: Карточка бота — свитч → капсула «Авто»

## Design Question

Владелец: авто-режим и тумблер активации бота — теперь одно и то же понятие.
Как оформить контрол на карточке бота (BotsPage / Bot.prefab footer) в стиле
капсулы «Авто» из top-bar страницы мессенджеров (locked-спека
`docs/design/ui-restyle/chats-topbar-spec.md`)?

Ключевой факт из кода (`Bot.cs`): статус-пилюля «Активен/Неактивен» — прямая
функция этого же свитча (выкл → красный «Неактивен»). Сегодня карточка
показывает одно состояние **тремя** сигналами: пилюля + подпись + свитч.
Варианты различаются тем, сколько сигналов остаётся.

## Variants

- **Baseline: Сегодня** — iOS-свитч 150×84 + подпись «Бот работает / Бот на паузе» + статус-пилюля. Точка отсчёта.
- **A: Пилюля из шапки** — минимальный ход: свитч заменён капсулой 1:1 из топ-бара (76h, точка + «Авто»; вкл = PositiveBg/PositiveInk, выкл = кольцо Border + полая точка). Подпись и статус-пилюля не тронуты.
- **B: Сегмент «Авто | Пауза»** — футер целиком становится утопленной лункой в языке переключателя каналов (tier-2 шапки). Контрол сам себя называет; подпись не нужна; самая большая цель касания.
- **C: Компакт без футера** — карточка 360 → 232 ед. Капсула встаёт в строку, статус-пилюля растворяется: связь = точка на аватаре (зелёная/синяя-мигает), авто = капсула, «Подключение…» уходит в подзаголовок. Один сигнал на одно понятие. **← выбран как направление.**
- **C2 (раунд 2, правки владельца)** — синтез C: точка на аватаре убрана (непонятна её роль); при подключении **моргает само слово «Подключение…»**; под именем — **тип бизнеса + значки каналов** (brand-иконки WhatsApp #25D366 / Telegram #2AABEE): цветной = канал подключён и включён; серый (InkTertiary, «как деактивирован») = подключён, но канал выключен тумблером в настройках бота (isOnWhatsapp/isOnTelegram); нет значка = канал не подключён. Демо-состав: Цветы = оба цветных, Автозапчасти = WA цветной + TG серый, Ремонт = «Подключение…», Школа = только WA.

Общее поведение во всех вариантах (кроме baseline): выкл → вкл — диалог
«Включить авто-режим?» (копия из locked-спеки шапки), вкл → выкл — мгновенно.

## What to Look For

- **Дублирование сигналов:** в A и B пауза даёт одновременно выключенную капсулу И красную пилюлю «Неактивен». Это полезное подтверждение или шум? (C отвечает «шум» и убирает пилюлю.)
- **Читаемость как переключателя:** свитч выглядит «трогаемым» сам по себе; пилюля A может читаться как статус, а не кнопка. Сегмент B — самый однозначный контрол из трёх.
- **Цвет:** капсула использует PositiveBg/PositiveInk как в шапке — старая резервация «#34C759 только для свитча активации» растворяется вместе со свитчем (одно понятие — один вид). Если нужен более громкий зелёный — это отдельный запрос.
- **Плотность:** C делает список в ~1.5 раза плотнее — важно при 4+ ботах.
- **Цель касания:** капсула визуально меньше свитча; в реализации хит-зона расширяется прозрачным паддингом до ≥96 ед., как у пилюли в шапке.
