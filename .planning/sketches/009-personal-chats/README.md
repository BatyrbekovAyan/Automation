# Sketch 009: Личные и рабочие чаты

## Design Question

ИИ-сотрудник работает на личном номере владельца. Ему нельзя отвечать родным, друзьям и всем, кому не надо, —
только тем, кто пишет по делу. Как это устроить, чтобы владельцу почти ничего не приходилось настраивать, а
ошибка была в безопасную сторону (лучше промолчать, чем ответить маме)?

Дизайн-документ: `docs/superpowers/specs/2026-10-25-personal-chats-design.md`.

## How to View

open .planning/sketches/009-personal-chats/index.html

Тёмная тема приложения («Графит» × «Чернильный», значения из `Theme_Dark.asset`). Всё, что выглядит кнопкой,
нажимается: галочки, «В личные», «В рабочие», плашка «Личный», имя в шапке рабочего чата, переключатели.

## Раунды

1. **Три равных состояния чата** («Авто» / «Выбрать» / «Личный»), метки «Выбрать» на чатах контактов —
   отвергнуто: «Авто» и «Выбрать» — одно понятие (переключатель «Авто» горит или нет), а «Личный» — отдельная
   категория; слово «Выбрать» на чатах выглядит как просьба что-то выбрать.
2. **Режим — только капсула «Авто»**, личные чаты спрятаны в папку «Личные» (как «Архив» WhatsApp), контакты
   по умолчанию с выключенным «Авто». Отвергнута часть: владельцы сохраняют постоянных клиентов в контакты, но
   правило «контакт = выключенное Авто» и два переключателя «Авто для…» в настройках непонятны.
3. **Контакты и старые переписки — личные по умолчанию, клиенты — исключения владельца.** При подключении
   экран «Кто из них клиенты?» (всё личное, галочкой — клиенты). Переключатели «Авто для…» убраны.
4. **Уточнения:** две строки настроек («Личные чаты» и «Отметить клиентов») объединены в одну — папку с
   режимом «Изменить»; постоянная карточка «Сделать рабочим» в личном чате заменена плашкой-кнопкой «Личный»;
   «Сделать личным» в рабочем чате — нажатием на имя в шапке (выбор владельца 2026-10-25).

## Экраны (итог)

1. Сразу после подключения — «Кто из них клиенты?» (папка «Личные» в режиме выбора).
2. Рабочий список: клиенты и новые люди, строка «Личные» с серым счётчиком, свайп «В личные».
3. Папка «Личные»: свайп «В рабочие», «Изменить»; у групп и каналов действия нет.
4. «Личные» → «Изменить»: несколько клиентов сразу.
5. Личный чат: плашка «Личный» → окно «Сделать чат рабочим?» (текст по режиму и свежести сообщения).
6. Рабочий чат: имя в шапке → «Сделать личным».
7. Настройки → Основное: одна строка «Личные чаты».
